# M3 — Reasoning engine (deterministic, no LLM)

Goal: `backend/mmc/engine/` Bayesian core + VOI planner + KP packs so each sim scenario converges to the true hypothesis. No LLM calls; Observations come from pytest fixtures. M0–M2 committed. Do NOT: ECU writes, non-Meta APIs, LLM-set probabilities, images as evidence, pre-hackathon imports, plaintext full VINs.

## 1. Files to create (exact paths)

- `backend/mmc/engine/__init__.py`, `bayes.py` — `update(posteriors, outcome, likelihoods)` with uniform default for unlisted hypotheses; normalize; `dependency_groups` merge (STFT+LTFT = one feature).
- `backend/mmc/engine/physics.py` — `maf_expected(rpm, disp_l, map_kpa, baro_kpa)`, `trim_rpm_split(idle, cruise)`, `o2_switching_ok(samples)`, `ect_plateau_ok(series)`, `voltage_ok(v, engine_on)`; SPEC §5 heuristics, labelled generic.
- `backend/mmc/engine/evaluator.py` — maps (expected, measured) → discrete outcome per `kp_test.evaluator`; source priority manual_page > kp > physics.
- `backend/mmc/engine/planner.py` — EIG/score, tool+level+safety+already-done filters, missing-evidence, stop rule.
- `backend/mmc/engine/stoprule.py` — `should_stop(top_p, best_eig)`: top ≥ 0.85 and best EIG < 0.05 bits, or no positive-score test.
- `backend/mmc/engine/trace.py` — trace entry per `hypothesis.json` (`seq, evidence_id, test_id, prior, posterior, likelihood_ratio, lr_source, text_L1/L3`).
- `backend/mmc/kp/__init__.py`, `loader.py` (YAML validate + likelihood normalization), `packs/ford_gen_v1.yaml`, `packs/generic_gas_v1.yaml`.
- `backend/tests/fixtures/sim_scenarios.py` — Python port of [Elm327Sim.kt](/home/dreamz/mmc/android/app/src/main/java/dev/dreamz/mmc/elm/Elm327Sim.kt) vehicle math (ECT tau 300 s→95 °C / 70 °C plateau; trims; MAF=0; IAT −40; DTCs; Mode 06 counts) emitting Observation sequences per scenario; no Android needed.
- `backend/tests/test_bayes.py`, `test_physics.py`, `test_evaluator.py`, `test_planner.py`, `test_kp_loader.py`, `test_engine_scenarios.py`, `test_engine_replay.py`, `test_engine_properties.py`.

## 3. Planner (SPEC §5 formula)

`EIG(t) = H(P) − Σ_o P(o)·H(P|o)`; `score = EIG / (1.0·minutes + 5.0·usd + 3.0·risk)`. Hard filters: `tools ⊆ user_tools`, `min_level ≤ user_level`, `safety_gate` acknowledged (gates are code: unacked test → `blocked_reasons`, never ranked runnable), not already performed under same conditions. `missing_evidence`: top-3 hypotheses × unobserved zero-cost features sorted by EIG. Likelihoods validated to sum to 1 ± 1e-9 per row.

## 4. Acceptance criteria → named tests

| Criterion | Test(s) |
|---|---|
| True hypothesis ranked #1, p ≥ 0.8 within ≤ 4 tests, every scenario | `test_engine_scenarios.py::test_scenario_converges[healthy\|maf_unplugged\|iat_unplugged\|vacuum_leak\|fuel_fuse_removed\|coil_unplugged\|thermostat_stuck_open]` (loop planner→fixture outcome→`bayes.update`, ≤ 4 steps) |
| Planner never returns test with tools ⊄ user tools or min_level > level | `test_planner.py::test_tool_filter_excludes_multimeter`, `test_planner.py::test_level_filter_excludes_L2_for_L1_user`, `test_planner.py::test_gated_test_blocked_until_ack` |
| Replay reproduces identical posteriors (bitwise after 1e-9 rounding) | `test_engine_replay.py::test_replay_posteriors_bitwise_stable` (rerun observation sequence, compare `round(p,9)` bytes) |
| Property: posteriors sum to 1 ± 1e-9 | `test_engine_properties.py::test_posteriors_sum_to_one` (hypothesis-state-machine fuzz) |
| Property: no negative probabilities | `test_engine_properties.py::test_no_negative_posteriors` |
| Unit: bayes math, EIG, physics, schema validation | `test_bayes.py`, `test_planner.py::test_eig_*`, `test_physics.py::test_maf/trim/o2/ect/voltage_*`, `test_kp_loader.py::test_likelihood_rows_sum_to_one` (validates `hypothesis.json`, `next_test.json`, `test_result.json` examples) |

## Ambiguities resolved

- SPEC §5 stop rule uses P(top) ≥ 0.85; M3 criterion uses p ≥ 0.8 to pass — engine implements 0.85, tests assert 0.8 (engine stricter than test).
- `ignition_misfire_cyl` parameterized by cylinder n via Mode 06 outcome payload; single hypothesis entry, n in trace `measured`.
- Uniform-default likelihood applies per-outcome-count of that test; loader fills and renormalizes missing rows.
- `healthy` hypothesis added (prior .15, others scaled) since one scenario is healthy; `other` stays .10 leak node.
