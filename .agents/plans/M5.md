# M5 Vision — plan (spike first, then build)

Source of truth: AGENTS.md "Meta client rules", API contracts, M5 acceptance, Do NOT; SPEC §4 model map, §7 vision pipeline/cost/latency/upload; PLAN Days 1–3. M0–M4 done. Key comes from `~/.config/meta/model-api.env` as MODEL_API_KEY at runtime only — never printed, never committed, never in fixtures.

## 0. Spike (Day 1, before any M5 code)

1. `backend/mmc/meta/client.py` — one OpenAI-SDK Responses client: base_url=META_BASE_URL, api_key=MODEL_API_KEY, pinned model IDs from env, 429 retry (exp backoff+jitter, honour Retry-After), per-call cost estimate + hard refuse past BUDGET_USD_HARD_STOP, every call appended as `llm_call`/`sam_call` event with sha256, disk cache keyed by sha256(canonical request) so REPLAY_USE_CACHED_LLM=true replays cost nothing.
2. `backend/mmc/meta/spark.py` — one image-understanding call on the fixture photo: vehicle-context prompt, structured JSON `{components:[{name,sam_concept,confidence}], anomalies:[{type,region_hint,confidence}]}` (~1024px long side).
3. `backend/mmc/meta/sam.py` — one SAM 3.1 image call: single noun-phrase concept from step 2 (e.g. "air filter housing"), plus one box-prompt call; parse with `meta_sam_parser`.
4. Fixture photo: CC0/public-domain engine-bay image in `backend/tests/fixtures/images/engine_bay_01.jpg` (+ `SOURCE.txt`: URL, author, licence). If no download works, generate a synthetic labelled engine-bay diagram instead and note it.
5. Record the exact verified request/response shapes (Spark + SAM, including box/point grammar behaviour) in `docs/DECISIONS.md`. Spike exit: both calls succeed, shapes documented, cost logged.

## 1. M5 proper (order)

6. `backend/mmc/meta/{budget.py,spark.py,sam.py}` — finish: budget math from AGENTS.md prices (Spark 1.25/0.15/4.25 per M; SAM 2.50/1k images, 0.20/1k frames min 50/request); Spark structured-output validation against `packages/schemas/vision_*`; SAM one-concept-per-request + box/point prompts + video path (Files API `purpose:user_data`, MP4/MOV H.264 only).
7. `backend/mmc/vision/components.py` — Spark JSON → typed Observations via engine (`add_observation` path); assert no probability fields survive (engine-only posteriors).
8. `backend/mmc/vision/instruments.py` — Spark `{value,units,confidence,needs_retake}` (retake if <0.8); value becomes Evidence only after explicit user confirm.
9. `backend/mmc/vision/keyframes.py` — server-side validation/selection helpers mirroring on-device logic (sharpness threshold, dedup) for upload mode.
10. `backend/mmc/api/routes_vision.py` — `POST /sessions/{id}/vision/keyframe → {components[],anomalies[],overlays[]}`, `POST .../vision/instrument → {value,units,confidence,needs_retake}`; blobs in via existing `POST .../blobs`.
11. Android `camera/{CameraScreen.kt,KeyframeSelector.kt,ClipRecorder.kt}` — CameraX@15fps, Laplacian-variance sharpness + motion gate, ≤1 keyframe/3s + on-tap, auto torch, 5–10s H.264 clip upload, instrument confirm UI.
12. `scripts/eval_m5.py` — scores `backend/tests/fixtures/m5_eval/` (owner drops 10 engine-bay + 10 multimeter photos later; dir gitignored except README): overlay hit (≥1 correct labelled mask, human-judged list) and meter exactness (±1 last digit); prints 7/10 and 8/10 verdicts.

## 3. Test per acceptance item (all offline except noted)

- ≥7/10 overlays: `test_vision_routes.py` (recorded Spark+SAM fixtures → overlays present, schema-valid) + `eval_m5.py` on owner photos when they land.
- 8/10 meter ±1 digit: `test_vision_routes.py` instrument cases incl. `needs_retake` + confirm-gate test (no Evidence before confirm).
- Keyframe selector: `KeyframeSelectorTest.kt` (sharp/change/tap/torch-gate logic, no network).
- SAM video tracking: `test_vision_parse.py` with recorded video-segmentation response (≤3 objects).
- Spark→Observation, never probabilities: `test_vision_parse.py` asserts output has no `prior`/`current`/probability keys; engine posteriors unchanged by raw LLM output.
- Replay costs nothing: `test_meta_budget_cache.py` replays cached spike calls with REPLAY_USE_CACHED_LLM=true, asserts zero new spend.
- Budget hard stop: `test_meta_budget_cache.py` forces spend past BUDGET_USD_HARD_STOP, asserts refusal.
- Live opt-in: `test_vision_live.py` (`@pytest.mark.skipif(not os.getenv("MMC_LIVE_TEST"))`) — one Spark + one SAM call, skipped in CI.

## 4. Expected Meta spend (dev)

- Spike: ~2 Spark image calls (~$0.01) + ~3 SAM images (~$0.01) + 1 SAM video ≤300 frames (~$0.06) ≈ **$0.10**.
