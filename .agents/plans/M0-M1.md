# M0 (scaffold, schemas, CI) + M1 (event store) — implementation plan

Scope: AGENTS.md milestones M0–M1 only. Dates: PLAN.md Day 1 (Wed Oct 28, all-nighter). No M2+ code.
Assumptions: Python 3.12 + uv, Node 24, JDK 21 installed (PLAN.md Day-1 state). Empty repo except AGENTS.md, docs/, .env(.example), README.md.

## 1. Files to create (exact paths per AGENTS.md layout)

M0 scaffold:
- `packages/schemas/*.json` (11): vehicle, session, evidence, observation, test_performed, test_result, hypothesis, next_test, report, event, adapter_profile (draft 2020-12; expand AGENTS.md abbreviations with descriptions + examples).
- `backend/pyproject.toml` (py3.12, fastapi, uv; pytest + jsonschema dev deps), `backend/mmc/__init__.py`, `backend/mmc/store/__init__.py`.
- `backend/tests/test_schemas.py`, `backend/tests/test_event_store.py`, `backend/tests/fixtures/` (empty placeholder + README).
- `.github/workflows/ci.yml` (pytest + gradle test + web build), `scripts/dev.sh`, `scripts/replay_check.sh` (stub: exit 0, no fixtures yet).
- `.env.example` (keep; verify no secrets), `.gitignore` (check .env covered).
- Minimal `android/` + `web/` shells so CI has something to run: `android/settings.gradle`, `android/app/build.gradle`, stub test; `web/package.json` (build script), `web/vite.config.ts`, `web/src/main.tsx`.

M1 event store:
- `backend/mmc/store/event_store.py` (append, verify_chain, replay iterator, SQLite index).
- `backend/mmc/store/blobs.py` (sha256 content-addressed put/get under DATA_DIR).
- `data/` gitignored session dir convention (`DATA_DIR/./data`).

## 2. Order of work

1. Schemas first (source of truth): write 11 JSON files from AGENTS.md §Schemas verbatim ($id, required, enums), add `examples/` per schema.
2. Backend skeleton: pyproject + store package + tests dir.
3. Event store + blobs (M1 core): JSONL `{seq,ts,type,payload,payload_sha256,prev_hash,hash}`; hash = sha256(prev_hash + payload_sha256); SQLite index (seq, type, ts, hash); `iter_replay()` yields payloads in seq order.
4. Tests: schema-examples validation; chain tamper test; 10k-append perf test.
5. Scaffold shells: minimal android/web so CI matrices pass; `scripts/dev.sh` (uv run uvicorn + npm run dev).
6. CI + local verify: run all verification commands below.

## 3. Acceptance criteria → tests

M0a `scripts/dev.sh` boots backend + web: manual/smoke — run script, curl backend health + web port 200. (CI only checks builds, not boot.)
M0b schema files validate own examples: `backend/tests/test_schemas.py` — every `packages/schemas/*.json` validates its example via `jsonschema` Draft2020-12; fails on any mismatch.
M1a tamper breaks `verify_chain()`: `test_event_store.py::test_tamper_detected` — append 3 events, flip one payload byte in JSONL, assert `verify_chain()` False / raises; un-tampered chain True.
M1b 10k appends < 2 s: `test_event_store.py::test_append_10k_perf` — time 10k `append()` on tmp dir, assert < 2.0 s (local + CI).

Out of scope: API routes, engine/, KP packs, ELM/sim, replay bundle format (stub script only).

## 4. Exact verification commands

```
cd backend && uv run pytest -q
cd android && ./gradlew testDebugUnitTest assembleDebug
cd web && npm ci && npm run build
scripts/replay_check.sh backend/tests/fixtures/sessions/*.mmrec
bash -n scripts/dev.sh && scripts/dev.sh & sleep 5; curl -sf localhost:8000/health; curl -sf localhost:5173; kill %1
python -c "import json,glob,jsonschema,references; [jsonschema.Draft202012Validator(json.load(open(s))).validate(json.load(open(s.replace('.json','.example.json')))) for s in glob.glob('packages/schemas/*.json')]"
```

Key decisions: stdlib sqlite3 + hashlib only (no DB dep); JSONL is source of truth, SQLite is rebuildable index; Draft 2020-12 enforced in test.
